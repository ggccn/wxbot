# 微信 AI 桥（wxbot · 小鱼）

把一个**微信小号**接给一个 AI Agent，让它像真人一样跟你的朋友或自己聊天。

不是机器人账号、不走官方 API：收到消息时直接读本机微信 4.x 的库，回复时通过界面把字打进去发出去，发出去的消息在对方那里就是那个小号发的。

> ⚠️ **先看这里**：这属于对微信客户端的非官方自动化，有封号风险，只拿**专用小号**折腾，别上主号。见文末「风险与免责」。

---

## 它好玩的地方不在"能收发"

单纯的收发消息几十行就能写完。这套东西真正花了功夫的是**让它像个有记忆、有情绪、会主动的人**：

| 能力 | 说明 |
|---|---|
| 人格 | `PERSONA.md` 一段人设正文，字数可配，太长会被自动截断 |
| 长期记忆 | 每个联系人/群一份笔记，分「档案」和「时间线」，按消息水位增量整理，重启不丢 |
| 短期上下文 | 最近 50 条对话（可按字数裁剪），引用消息会解析成「对方引用了你说的话：…」 |
| 情绪 | 好感度、心情状态机，会影响回复语气和是否可以撒娇/闹脾气 |
| 好奇心 | 冷场时才追问，并且从对方**刚说的那句话**里挑细节；问过的方向记进笔记，不重复问 |
| 主动 | 定时问候 + 随机主动找人（每天限额、避免重复打扰）；也可手动触发「让她自己编一句发给某人」 |
| 表情包 | 自己维护一套分类表情库，也能直接发微信收藏的表情 |
| 动作描写 | `[[动作:喝口水]]` / `[[表情:开心]]` 这类标记会被解析成动作描述或表情图片 |
| 面板 | 本地 Web 面板，所有开关、话术、笔记都能改，不用碰配置文件 |
| 命令 | 微信里发 `/停` `/继续` `/状态` `/上限` `/同意` 等给主人用的命令 |

## 架构

```
微信 4.x 客户端 ──(读本地 SQLCipher 库 / UIA 驱动界面)──> Bridge
                                                          │
                                            白名单·防封·限流·排队·静音
                                                          │
                                              dsh headless（Agent 本体）
                                                 工具/文件/技能全在
                                                          │
                                                    ──> 微信界面发出
```

- **收**：读本机微信的本地库（SQLCipher，key 由客户端自己带），只读，不改库。
- **发**：UI 自动化。没有后台发送接口，所以每次发送都会短暂占用前台（约 1–3 秒）。
- **大脑**：DeepSeek Harness 的 `headless` 模式，用 `--json` 走 NDJSON，一次一问一答；它是带工具的真 Agent，能读写文件、跑命令、联网搜索。

## 快速开始

1. **准备微信**：Windows 上装微信 4.x 桌面版，登录一个**小号**（有封号风险，别用主号）。
2. **Python**：3.12 环境。
   ```bash
   python -m venv .venv
   .venv\Scripts\python.exe -m pip install -r requirements.txt
   ```
   唯一的运行时依赖是 [`wechatauto-replica`](https://pypi.org/project/wechatauto-replica/)（UI 驱动 + 库解密）。
3. **配置**：`copy config.example.toml config.toml`，把 `admin_wxids`、`allow_contacts` 换成你自己的 wxid。
4. **人格**：建 `%USERPROFILE%\wxbot_home`（或设环境变量 `WXBOT_HOME`），放一个 `PERSONA.md` 写人设，`notes/` 会自动生成。
5. **启动**：
   ```bash
   .venv\Scripts\python.exe run_v4.py
   ```
   看到「桥已启动」后，给你的小号发条消息试试。
6. **面板**：`panel.cmd`（或 `python panel.py 8765`），浏览器开 `http://127.0.0.1:8765`。

想看纯逻辑不想碰微信？`python run_mock.py` 用假适配器跑一遍对话流程。

## 文件地图

| 文件 | 职责 |
|---|---|
| `run_v4.py` | 进程入口：消息循环、心跳、自愈、主动消息计时 |
| `bridge.py` | 核心：提示词拼装、动作/表情解析、合并队列、命令、静音 |
| `adapters/wxa_adapter.py` | 微信 4.x 适配（收发、取图、表情、戳一戳） |
| `adapters/mock.py` | 假适配器，用来离线跑逻辑 |
| `brain.py` | `dsh headless` 子进程封装（超时、重试、会话复用） |
| `persona.py` / `memory.py` / `notes.py` | 人设加载、笔记整理、消息水位 |
| `mood.py` | 好感度与心情 |
| `proactive.py` | 定时/随机主动 |
| `safety.py` | 白名单、限流、日限额、重复检测 |
| `media_in.py` | 收到图片后的解密与转码 |
| `stickers.py` | 表情库索引 |
| `panel.py` | 本地 Web 面板 |
| `wxrecover.py` / `wxui.py` | 界面的兜底恢复、UI 操作封装 |
| `paths.py` | 统一路径（`WXBOT_HOME` 可覆盖） |

## 已知限制

- **只能 Windows**，且依赖微信 4.x 桌面版的界面结构；客户端一升级就可能需要重新校准坐标。
- **发送要抢前台**：用户正在打游戏/看视频时，窗口会闪一下。
- **不是官方接口**：随时可能因为客户端更新或风控策略而失效。
- 群聊只做「被 @ / 叫外号 / 接话」这几种场景，不做全自动群管理。

## 风险与免责

1. 这是**非官方**自动化，违反微信用户协议，可能导致**账号被限制或封禁**。请只用专用小号。
2. 不要用它做营销、加粉、群发——那既违反协议，也是这类项目把风控逼升级的原因。
3. 代码按「现状」提供，不做任何可用性/合规性担保；使用后果自负。
4. 里面的人设、表情、语气都是我按自己需求调的，**删掉换成你自己的**。
